# Presentation Design Principles

Use this guide before creating a deck or custom theme from scratch.

## Start With Communication

- Define the audience action or understanding the deck must produce.
- Give each slide one claim. Split competing claims into separate slides.
- Write the claim as the title; avoid generic labels such as "Overview" or "Features."
- Move explanation to speaker notes. Slides should support the speaker, not duplicate a document.
- Use a visual only when it clarifies evidence, structure, contrast, scale, sequence, or emotion.

Duarte recommends one idea per slide to reduce overload. Canva likewise recommends concise phrases instead of transcript-like bullets.

## Build Visual Hierarchy

Create an intentional reading order using, in priority order:

1. scale;
2. placement;
3. contrast;
4. proximity and grouping;
5. color.

Make one element dominant. Keep secondary and tertiary levels visibly quieter. If every item has the same size, container, and color, the viewer has no entry point.

Nielsen Norman Group identifies scale, color/contrast, and grouping as core hierarchy tools. It also notes that polished designs use consistent typography, a refined palette, and grid alignment.

## Use A Grid Without Looking Like A Dashboard

- Use an 8px base spacing unit and multiples such as 16, 24, 32, 48, 64, and 80px.
- Establish stable left and right key lines across slides.
- Align text baselines and container edges to those key lines.
- Use grids as structure, not as a reason to make every item an equal card.
- Introduce contrast through asymmetry, negative space, scale, and image/text juxtaposition.
- Preserve a small family of layouts: statement, image-led, comparison, process, evidence, code, and closing.

IBM Carbon's 2x Grid uses an 8px mini-unit and stresses key lines, rhythm, hierarchy, contrast, negative space, and asymmetry. It explicitly warns that equal scale across all content removes orientation.

## Control Typography

- Prefer one type family with 3-4 deliberate weights.
- Use a constrained type scale rather than arbitrary sizes.
- Keep titles short enough to remain large.
- Keep body lines comfortably short; do not stretch paragraphs across the full slide.
- Use sentence case consistently. Avoid excessive all caps except for short labels.
- Use bold for hierarchy, not for entire paragraphs.
- Check Japanese line breaks; prevent isolated punctuation and awkward one-character wraps.

## Use Color Deliberately

- Start with neutral background, neutral text, and one accent. Add a second accent only when it encodes a distinct meaning.
- Reserve the strongest color for the focal point.
- Do not use color as the only signal; reinforce it with labels, weight, shape, or position.
- Meet at least WCAG AA text contrast: 4.5:1 for normal text and 3:1 for large text.
- Avoid low-contrast gray body copy and accent-colored small text.

## Compose With Background Images

- Choose an image with negative space where the title can sit; do not fight a busy subject.
- Use `cover` for immersive slides and split backgrounds for content-heavy slides.
- Crop the same image differently only when each crop serves a different composition.
- Apply brightness or opacity filters and a restrained overlay instead of placing text directly on high-detail areas.
- Keep text contrast compliant after rendering; inspect the actual crop in every output format.
- Prefer local image assets for reproducible and offline rendering.
- Record the source and license even when attribution is optional.

## Create Rhythm Across The Deck

- Alternate dense and sparse slides.
- Follow a multi-item slide with a single-message slide.
- Use section breaks to reset attention.
- Reuse typography, palette, and key lines while varying composition.
- Prefer a designed sequence over a collection of independent templates.

## Avoid Common Failure Modes

- Do not center every slide.
- Do not use equal cards as the default answer to every information problem.
- Do not add gradients, circles, waves, or shadows without a communicative role.
- Do not use tiny captions to rescue an overloaded slide.
- Do not place a heading, paragraph, and grid on every page in the same positions.
- Do not decorate before the narrative and hierarchy are clear.
- Do not stretch or crop imagery without checking the rendered result.

## Review Checklist

- Can the slide's claim be understood in three seconds without reading every word?
- Is there one obvious first place to look?
- Does every element earn its space?
- Are related items close and unrelated items separated?
- Do key lines and spacing feel consistent across the deck?
- Does this slide add visual rhythm rather than repeat the previous layout?
- Is all text legible at presentation distance and sufficiently contrasted?
