# バケット作成

Cloudflare R2 Storageに新しいバケットを作成する。

## コマンド

```bash
r2up create <name>
```

## 引数

- `<name>`: 作成するバケット名

## 実行タイミング

- ユーザーが明示的にR2バケット作成を依頼したとき

## 手順

1. `r2up buckets` を実行して既存バケット一覧を取得する
2. 既存バケット一覧に同じバケット名があるか確認する
3. 同名バケットが存在する場合は、`r2up create <name>` を実行せず、既に存在することをユーザーに伝える
4. 同名バケットが存在しない場合だけ、`r2up create <name>` を実行する
5. 成功または失敗の結果をユーザーに伝える
