# ファイルアップロード

ローカルファイルをCloudflare R2 Storageの指定バケットへアップロードする。

## コマンド

```bash
r2up upload <bucket> <file>
```

## 引数

- `<bucket>`: アップロード先のR2バケット名
- `<file>`: アップロードするローカルファイルパス

## 実行タイミング

- ユーザーがローカルファイルをR2へアップロードしたいとき

## 手順

1. `r2up buckets` を実行して既存バケット一覧を取得する
2. 既存バケット一覧にアップロード先バケット名があるか確認する
3. アップロード先バケットが存在しない場合は、`r2up upload <bucket> <file>` を実行せず、対象バケットが見つからないことをユーザーに伝える
4. アップロード先バケットが存在する場合だけ、`r2up upload <bucket> <file>` を実行する
5. 成功または失敗の結果をユーザーに伝える
